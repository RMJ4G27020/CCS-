🎨 CSS Animations Demo

1. Fade In Animation

This box fades in smoothly when the page loads
@keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } } animation: fadeIn 2s ease-in;

2. Slide In Animation

This box slides in from the left side
@keyframes slideInLeft { from { transform: translateX(-100%); } to { transform: translateX(0); } } animation: slideInLeft 1.5s ease-out;

3. Continuous Rotation

⭐
@keyframes rotate { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } animation: rotate 3s linear infinite;

4. Bounce Effect

Bounce!
@keyframes bounce { 0%, 20%, 50%, 80%, 100% { transform: translateY(0); } 40% { transform: translateY(-30px); } 60% { transform: translateY(-15px); } } animation: bounce 2s ease infinite;

5. Color Change Animation

Watch the colors change continuously!
@keyframes colorChange { 0% { background: #f44336; } 25% { background: #4CAF50; } 50% { background: #2196F3; } 75% { background: #FF9800; } } animation: colorChange 4s ease infinite;

6. Pulse Effect

This element pulses with a shadow effect
@keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.05); } 100% { transform: scale(1); } } animation: pulse 2s ease infinite;

7. Typing Effect

CSS animations are awesome! 🚀
@keyframes typing { from { width: 0; } to { width: 100%; } } animation: typing 3.5s steps(40) 1s both;
